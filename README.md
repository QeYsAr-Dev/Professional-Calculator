## 📖 About

**Professional Calculator** is a Python-based command-line calculator designed to provide a collection of useful mathematical operations through a simple and organized interface.

The project was created as a practical Python project to improve programming skills while implementing mathematical operations, user input handling, calculation history, and error management.

> **Simple idea. Practical implementation. Continuous improvement.**

---

## ✨ Features

The calculator supports a variety of mathematical operations:

* ➕ **Addition**
* ➖ **Subtraction**
* ✖️ **Multiplication**
* ➗ **Division**
* 🔢 **Power**
* √️ **Square Root**
* `%` **Modulus**
* 📊 **Average**
* `!` **Factorial**
* 🔢 **Unlimited Number Addition**
* 📝 **Calculation History**
* 🛡️ **Error Handling**
